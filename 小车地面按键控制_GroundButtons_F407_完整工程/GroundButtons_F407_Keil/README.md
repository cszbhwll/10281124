# STM32F407 地面按键调试版

按键每次触发一个低速限时动作。KEY0 前进，KEY1 原地左转，WK_UP 原地右转；默认速度档位 2，每次约 350 毫秒后自动停车。KEY2 请求停止并锁定。

| 主板按键 | 功能 |
| --- | --- |
| KEY0（PE4） | 前进 |
| KEY1（PE3） | 车身原地左转 |
| WK_UP（PA0） | 车身原地右转 |
| KEY2（PE2） | 停止并锁定 |
| RESET | 重新初始化。全部动作键松开后才接受新动作 |

按键不需要串口 enable。短按启动一次，长按不会重复。动作正在运行时，其他动作键不排队。松开动作键再按，才会执行下一次。按 KEY2 锁定后，松开全部按键并按 RESET 解锁。

## 地面试车步骤

因之前出现过复位后电机持续转动，先把底盘架稳，让四轮离地，确认驱动板动力开关可随手关闭。烧录 Firmware/GroundButtons_F407.hex 后，先给驱动板上电，再给主控上电或按实体 RESET。串口应看到 READY GroundButtons。确认待机时车轮静止，先按 KEY0。确认向前并在约 350 毫秒后停下，再分别短按 KEY1 和 WK_UP，检查原地左右转向及停车。确认悬空测试正常后，再在地面用同样短按依次测试。

按键停止依赖主控和驱动板通信。出现异常持续转动时，立即切断驱动板动力。

## 工程与参数

Keil 工程为 MDK-ARM/GroundButtons_F407.uvprojx。在 Tune/ground_tuning.h 修改 GROUND_BUTTON_SPEED 和 GROUND_BUTTON_TIME_MS，然后重新编译烧录。轮位沿用已确认的 FL=M3、FR=M4、RL=M1、RR=M2，前进符号全为 -1。

沿用原接线和跳线，PB8/PB9 为 I²C，驱动板的 I²C 5V 留空。编译通过；实车的左右转向和停止仍需现场确认。
